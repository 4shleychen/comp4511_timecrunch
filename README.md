# TimeCrunch

TimeCrunch is a quick workout app. Enter how much time you have, follow a short routine with a timer, then take a photo and share it with friends.

# What you need

The Expo Go app on your phone, from the App Store or Google Play.

# How to set up the app

1. Download the project and open a terminal in the project folder.

2. Install the project's packages by running: npm install

3. Start the app by running: npx expo start

4. A QR code will appear in the terminal, scan it on your phone. 

5. The app will open in Expo Go on your phone.

# Trying the app

On the sign in screen, enter any email and any password to sign in.

To see the error message and the forgot password link, enter wrong as the password.
